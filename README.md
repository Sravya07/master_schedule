## 💡 Design Philosophy

**This is a PCOS + night-shift + injury-recovery optimized system.** Key principles:

- **Strength > cardio** for insulin resistance (3×/week non-negotiable)
- **Iron + Vit C pairing** every meal (anemia treatment, not just nutrition)
- **Proprioceptive retraining** (ankle protocol runs 16 weeks, then lifetime 2×/week)
- **Consistent sleep window** (1:45–9:00 AM every day, even weekends — nervous system anchor)
- **Cycle-phase adaptation** (seed cycling, drink rotation, meal picks, supplement timing)
- **Cool environment** (hyperhidrosis management — no HIIT, no hot showers, AC required)
- **No guessing** (every phase is data-driven, every meal is tracked, every workout is logged)
